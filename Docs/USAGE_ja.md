# MarbleEx 使用説明書 (USAGE_ja.md)

`MarbleEx` は、lilToon 拡張機能として動作するシェーダーモジュールです。  
水中に落とした絵の具のような動的マーブル模様、ゆらめくオーロラ、生物的なボロノイ細胞、水底のカースティクス（光の網目）などのアニメーションパターンをマテリアルへ簡単に追加できます。

## 1. 基本設定 (Common Settings)

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Enable MarbleEx** | Toggle (0/1) | `Off (0)` | MarbleEx 機能全体の有効 / 無効を切り替えます。 |
| **Pattern** | Enum | `Marble` | 生成するパターンの種類を選択します。<br>・**Marble**: ドメインウォーピングによる動的流体・マーブル模様<br>・**Aurora**: 縦方向にゆらめくオーロラ・雲流<br>・**Voronoi**: 呼吸・脈動するボロノイ細胞パターン<br>・**Caustics**: 2層重畳による水底の光の網目模様 |
| **UV Mode** | Enum | `Main UV` | パターンのマッピングに使用する座標系を選択します。<br>・**Main UV**: メッシュのメインUVに沿って配置<br>・**Object Space**: オブジェクトローカル空間位置（メッシュのシーム感を軽減）<br>・**World Space**: ワールド空間位置（ワールドに固定されたゆらぎ表現など） |
| **Blend Mode** | Enum | `Replace` | パターンをベースカラーへ合成する方法を選択します。<br>・**Replace**: ベースカラーを模様で置き換えます。素材そのものが模様である **Marble / Voronoi** 向けです。<br>・**Add**: ベースカラーへ加算します。外から投影された光である **Aurora / Caustics** はこちらが適切で、ベーステクスチャの質感を残したまま光が乗ります。<br>・**Screen**: スクリーン合成。Add より白飛びしにくく、明るいベースカラーでも階調が残ります。 |

> **補足**: `Aurora` / `Caustics` を選択して `Blend Mode` が `Replace` のままの場合、インスペクター上に `Add` への切り替えボタンが表示されます。

## 2. マスク設定 (Mask Settings)

模様の適用範囲や強さをテクスチャで制御します。※マスクテクスチャのタイリング・オフセットは常に**メインUV基準**で適用されます。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Mask** | Texture 2D | `white` | 模様を適用する範囲を制御するマスクテクスチャです。黒(0)の場所には模様が適用されません。 |
| **Mask Channel** | Enum | `R` | マスクテクスチャのどのチャンネル（R / G / B / A）を判定に使用するか選択します。 |
| **Invert Mask** | Toggle (0/1) | `Off (0)` | マスクの白黒（明暗）を反転させます。 |

## 3. パターン共通設定 (Pattern Attributes)

全パターンに共通して影響するアニメーション速度やスケール、合成度合いの設定です。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Scale** | Float | `4.0` | パターンの大きさ（密度）を調整します。値を大きくすると模様が細かくなります。※`Caustics` のみ内部で密度を 2.5 倍しているため、他パターンと同じ `4.0` 前後の設定で網目が適切な細かさになります。 |
| **Speed** | Float | `0.5` | パターンのアニメーション速度を調整します。`0` にすると動きが停止します。※`Caustics` のみ内部で 2 倍しているため、`0.3`〜`0.9` で実際の水面と同じ 1〜3 Hz のきらめきになります。 |
| **Detail (fBm Gain)** | Range (0.0 - 1.0) | `0.5` | ノイズの複雑さ・細かい起伏の強さを調整します。値を上げると密で複雑な模様になります。 |
| **Blend** | Range (0.0 - 1.0) | `1.0` | ベースカラー（マテリアル本来の色）とMarbleExパターンの合成強度を調整します。 |
| **Emission** | Range (0.0 - 4.0) | `0.0` | 模様自体を発光（エミッション）させます。`0` 以上に設定すると暗所でも模様が輝きます（HDR入力カラー対応）。 |

## 4. アルファブースト機能 (Alpha Boost)

ドレスの薄布やドレスのフリル、半透明マテリアル（Rendering Mode: Transparent 等）において、模様部分の不透明度を持ち上げて視認性を維持する機能です。ベースのアルファ値を引き下げることはありません。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Alpha Boost** | Enum | `Off` | アルファ補正のモードを選択します。<br>・**Off**: アルファ値を補正しません。<br>・**Saturation**: 彩度が高い部分の不透明度をアップ<br>・**Luminance**: 明度（輝度）が高い部分の不透明度をアップ<br>・**Pattern**: パターンの分布マスク自体に応じて不透明度をアップ |
| **Alpha Boost Strength** | Range (0.0 - 1.0) | `1.0` | アルファ持ち上げの適用強度です。 |
| **Alpha Boost Contrast** | Range (0.1 - 8.0) | `1.0` | アルファ持ち上げ部分のグラデーションのコントラスト（境界のくっきり感）を調整します。 |

## 5. カラーパレット (Color Palette)

パターンのグラデーションを定義する3色のカラーセットです。すべてHDRに対応しているため、ブルーム（発光）表現が可能です。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Color 1** | Color (HDR) | 暗い青紫 | グラデーションのベースとなる背景色・谷の色です。 |
| **Color 2** | Color (HDR) | 中間の紫 | グラデーションの中間色です。 |
| **Color 3** | Color (HDR) | 明るい白紫 | グラデーションの山・ハイライト・エッジ部分の色です。 |

## 6. パターン別個別パラメーター (Pattern-Specific Parameters)

選択した `Pattern` に応じて専用に効く調整項目です。

### Marble (マーブル / 流体)

絵の具を水に落としたような流体とうねりの表現。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Warp Strength** | Range (0.0 - 4.0) | `1.2` | ドメインウォーピングによる渦や歪みの歪曲強度を調整します。 |
| **Vein Frequency** | Range (0.0 - 32.0) | `8.0` | マーブル模様の筋（縞模様）の周期・密度を調整します。 |
| **Contrast** | Range (0.1 - 4.0) | `1.4` | 色の境界線のくっきり度合いを調整します。 |

### Aurora (オーロラ / 雲流)

カーテン状にゆらめく光や星雲の表現。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Vertical Stretch** | Range (1.0 - 16.0) | `5.0` | ノイズを縦方向に引き伸ばす倍率です。値を大きくすると縦縞状のカーテン表現になります。 |
| **Sharpness** | Range (0.5 - 8.0) | `2.5` | 光の帯のシャープさ・鋭さを調整します。 |

### Voronoi (ボロノイ / 細胞・脈動)

生物の皮膚や生きているような細胞の表現。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Edge Width** | Range (0.0 - 0.5) | `0.08` | ボロノイ細胞同士の境界線（エッジ）の太さです。`0` にすると境界線なしのセル表現になります。 |
| **Breath** | Range (0.0 - 1.0) | `0.7` | 時間経過に伴う細胞の膨張・収縮（呼吸運動）の強度を調整します。 |
| **Cell Variation** | Range (0.0 - 1.0) | `0.6` | セルごとの明暗・色みのバラつき（個体差）の強さを調整します。 |

### Caustics (カースティクス / 水底の光)

水面下で揺らめく光の網目・屈折の表現。逆方向へスクロールする 2 層のボロノイからセル境界を光の線として抽出し、加算で重ねることで交差部が明るく輝く網目を作ります。

| 項目名 | 型 / 範囲 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **Sharpness** | Range (2.0 - 16.0) | `7.0` | 光の線の細さです。値を大きくするほど網目が細くシャープになります。`4` 前後で太くにじんだ光、`10` 以上で繊細な糸状になります。 |
| **2nd Layer Scale** | Range (1.1 - 2.5) | `1.6` | 2層目のボロノイノイズの相対スケールです。`1.0` に近づけると 2 層が干渉してモアレになるため、`1.6`〜`1.7` 付近が最も自然です。 |
| **Water Warp** | Range (0.0 - 1.5) | `0.5` | 水面のうねりによる座標の歪みです。`0` にすると直線的な多角形（割れガラス調）、大きくするほど有機的にうねります。`1.0` を超えると溶けたような表現になります。※`0` にするとノイズ 1 段分の計算を省略できるため、Quest 向けの軽量化に使えます。 |

> **描画品質について**: 光の線が 1 ピクセルより細くなる距離では、線幅を自動的に広げたうえで同じ分だけ暗くします（エネルギー保存）。これにより遠景やアバターを傾けたときのちらつきを抑え、白飛びせずパターンの平均輝度へ収束します。

## 7. 実用テクニック & Tips

- **シーム（縫い目）を目立たなくしたいとき**
  `UV Mode` を `Object Space` または `World Space` に設定することで、UV展開の境界線をまたいでもシームレスに模様が連続します。
- **衣装の装飾や特定部位だけに適用したいとき**
  `Mask` テクスチャを割り当て、`Mask Channel` で使用するチャンネルを指定してください。衣装のマスク画像と共通化することも可能です。
- **暗闇で幻想的に光らせたいとき**
  `Emission` を `1.0`〜`2.0` 程度に上げ、`Color 1 ~ 3` のHDR値を高く設定すると、VRChat等の暗いワールドで綺麗に発光します。
- **水中にいるようなカースティクスを作りたいとき**
  `Pattern` を `Caustics`、`Blend Mode` を `Add`、`UV Mode` を `World Space` に設定してください。ワールド空間に固定されるため、アバターが動いても光の網目がその場に留まり、本当に水面下にいるように見えます。パレットは `Color 2` を淡いシアン（`0.4, 0.85, 1.0` 付近）、`Color 3` を白の HDR 値 `2.0` 程度にすると水中光らしい色になります。

- **シースルー衣装での模様のくっきり化**
  半透明衣装で模様が見えにくくなる場合は、`Alpha Boost` を `Pattern` または `Luminance` に設定し、`Alpha Boost Strength` を調整することで模様部分のみしっかりと発色させることができます。
